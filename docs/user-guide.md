# 用户使用文档

> 适用对象：平台运营、旅行社老板/租户管理员、计调、销售、财务、导游、分销商、供应商、景区员工、游客。

## 1. 登录与入口

### 1.1 管理后台（PC）

地址：`http://<服务器>/`（本地默认 `http://127.0.0.1/`）

1. 打开登录页，选择「租户端」或「平台端」。
2. 租户端输入：租户编码（如 `HLJ`）、账号、密码；平台端输入：`system` / `admin123`。
3. 登录后进入工作台；平台端默认进入「全国数据看板」。

演示账号见项目 `README.md`。

### 1.2 平台端与租户端切换

- 平台超管登录后，顶部有「全国视图 / 选择租户」下拉框。
- 选择租户后进入该租户的**只读下钻视图**：页面顶部显示「下钻只读」，任何修改操作会被后端拒绝（403）。
- 点击「全国视图」恢复跨租户统计。

### 1.3 手机端

- 小程序：微信搜索/扫码进入（开发阶段用微信开发者工具导入 `miniprogram/`）。
- H5 门户：`http://<服务器>:8082/`。
- App：安装包由 Flutter 构建产物提供。

## 2. 平台运营（system 超管）

### 2.1 开通租户

1. 「租户管理」→「开通租户」。
2. 填写租户编码（英文大写，用于编号前缀）、旅行社名称、省市、联系人、电话、开通月数、配额（用户/产品/订单/存储）。
3. 保存后系统自动创建租户管理员：账号 `admin`，初始密码 `admin123`，并授予全部租户菜单。

### 2.2 续期/停用/配额

- 续期：列表「续期」→ 输入月数；到期状态自动恢复为正常。
- 停用：停用后该租户全部用户无法登录，数据保留。
- 配额：编辑租户可调整；租户新增产品达到产品配额时会被拦截。

### 2.3 全局字典与平台参数

- 全局字典：目的地、出发地、线路天数、订单状态、结算类型、证件类型、退改规则模板等；租户只能引用/扩展，不能修改标准项。
- 平台参数：成团最低人数、出团预警天数、结算账期、电子合同/OTA/短信开关；保存后实时生效。

### 2.4 全国看板与审计

- 看板展示旅行社数、产品数、订单数、销售额、会员数与租户明细。
- 平台审计可检索所有租户操作；平台超管的下钻、停租户、改参数均留痕。

## 3. 租户管理员

### 3.1 工作台

展示今日订单、累计销售额、产品数、会员数、7 日内出团、成团/出团预警（红黄灯）、配额使用。

### 3.2 产品（线路）管理

1. 「产品中心 → 线路产品」→「新增产品」。
2. 填写标题、品类、天数、出发地/目的地、价格、库存、成团人数、集合地点。
3. 「行程 D1~Dn」逐天填写景点/酒店/用餐/交通/导游/住宿，或点「按天数生成」。
4. 右侧上传封面图、相册；配置上架渠道（小程序/公众号/H5/App/OTA/分销）与多渠道报价。
5. 「图文详情」使用富文本编辑器（支持图片/视频/表格，粘贴图片自动上传对象存储）。
6. 中文/EN 标签页可录入英文标题与英文详情（未填显示红点）。
7. 保存后可「上架/下架」「配置渠道」「编辑」「删除」。

批量导入/导出：列表右上角「批量导入」下载模板填好后上传；「导出 Excel」导出全部产品。

### 3.3 排期与出团计划

1. 「排期管理 → 日历排期」按日历查看；点击日期查看当日团。
2. 「批量生成出团计划」选择线路、日期区间、每周几，一键生成。
3. 列表页可「指派导游」（选择导游后自动推送）、「计划书」下载 PDF（含行程/名单/计划明细）、「状态」手动流转。
4. 「出团预警」在首页与排期页红黄灯提示：临近出团、收客不足成团人数。

### 3.4 订单管理

- 订单列表按订单号/联系人/手机、状态、支付状态筛选。
- 操作：
  - 详情：游客名单（证件脱敏）、状态轨迹、支付/退款/核销记录。
  - 确认：名单确认后进入待确认/已成团。
  - 出团通知：推送公众号模板消息/站内消息。
  - 核销：输入订单号或扫码，选择门店/导游/闸口，防重复核销。
  - 退改：填写金额/原因提交，详情页审批通过后微信原路退款（模拟）。
- 导出游客名单：右上角「导出游客名单」。

### 3.5 计调资源

1. 「供应商档案」新增酒店/车队/餐厅/地接/门票供应商，设置账期与开放端账号。
2. 「采购单」选择供应商与资源、数量，系统校验库存（超售拦截）。
3. 供应商可通过开放端或后台确认采购单。
4. 排期页「OP 排团」可按排期匹配资源与导游建议。

### 3.6 导游管理

- 导游档案：姓名、导游证号、等级、手机号、语种、可带团时间、押金；身份证加密存储。
- 带团安排：查看推送记录与导游确认状态。
- 报账审核：查看门票/餐费/其他消费、单据照片，通过/驳回。

### 3.7 财务结算

1. 「结算单」→「发起结算」：按合作方/单团/订单。
2. 确认 → 审批通过 → 打款；状态：待确认/已确认/已结算/已归档。
3. 「电子发票」申请开票 → 开票。
4. 「分账管理」配置平台/景区/供应商分成比例，按订单执行分账，失败可重试。
5. 导出结算单 Excel。

### 3.8 分销管理

- 分销商/门市：维护账号、类型、独立商城名、佣金比例。
- 分销报价：选择分销商 → 新增/修改线路分销价。
- 佣金：订单完成后按比例入账，可手动入账。
- 「换线操作」「按报名人数排序」由分销端使用。

### 3.9 电子合同

1. 「合同模板」新增模板，内容支持 `{{contact}}`、`{{product}}`、`{{date}}`、`{{people}}` 占位。
2. 「合同列表」→「生成合同」选择订单与模板。
3. 「在线签署」：人脸校验（模拟）+ CA 证书，生成 PDF。
4. 「下载 PDF」「同步文旅局」（模拟）。
5. 合同验真：公开端 `GET /public/contracts/verify?contractNo=...` 仅返回摘要。

### 3.10 会员运营

- 会员列表：UnionID、等级、积分、累计消费、最近活跃；详情含订单/积分/优惠券。
- 优惠券：新建满减/折扣券，可「全员发放」。
- 营销活动：优惠券/满减/限时促销配置。
- 积分商城：商品上下架、兑换记录核销。
- 会员卡/储值：开卡、充值、余额流水。
- 复购分析：会员总数/活跃/沉默/等级分布/消费 TOP。

### 3.11 景区管理

- 景区档案：名称、等级、省市、地址、电话、开放时间、简介/公告/攻略、封面、经纬度。
- 门票产品：单票/联票/年卡/团队票/优待票、成人/儿童/团队价、有效天数、日限流、退改/核销规则。
- 票务库存：按日期+时段配置库存与团队预留。
- 客流看板：今日入园、分时段、区域容量与拥堵预警。
- 验票记录：核销码、闸口、操作人、时间。
- 二销/停车/导览：商户分成、车辆进出场计费、语音讲解点位。

### 3.12 内容与增长

- 社区审核：待审核/已通过/已拒绝，支持图片预览、通过/拒绝/删除；举报处理（下架/忽略）。
- 定制游：查看需求 → 报价 → 接受报价。
- 直播：配置直播/短视频挂载线路。

### 3.13 报表中心

- 经营报表：选择日期范围，查看订单数、销售额、退款、成团率、毛利、导游报账、结算金额、佣金；按线路/渠道图表；导出 Excel。
- 经营驾驶舱：今日订单/销售额/入园、7 日排期、成团预警、客源结构、会员结构。

### 3.14 系统设置

- 用户管理：新增账号、分配角色、重置密码。
- 角色权限：菜单树勾选；租户管理员角色不可删除。
- 数据字典：全局标准只读，租户自定义可增删。
- 租户配置：名称/Logo/客服/小程序 AppID/通知开关/出团模板/微信支付；密钥加密、回掩码。
- 对象存储：选驱动 → 填参数 → 连接测试（通过才可保存）→ 保存并应用 → 切换二次确认。
- 微信配置：小程序/公众号 AppID、Secret、服务器 URL、Token、EncodingAESKey、网页授权域名、开放平台 AppID；模板消息 ID；素材/标签/粉丝/群发。
- 消息配置：7 类模板 ID、启停、发送日志。
- 菜单可视化：小程序 tabBar / H5 导航 / App 导航 / 公众号菜单 / 后台导航，JSON 编辑 + 手机预览，保存实时生效。
- 审计日志：按操作人/动作/模块检索。

## 4. 导游端（小程序 / App）

1. 登录：选择「导游」，输入绑定导游档案的手机号（演示 `13800000006`）或 UnionID。
2. 「带团行程」：查看分配的出团计划（线路、日期、集合地点、收客数）。
3. 点选团 → 「客人点名」（应到/实到），查看游客名单（证件/手机脱敏）。
4. 「供应商直拨」：点击直接拨打酒店/车队/餐厅电话。
5. 「回团报账」：选择出团计划、费用类型（门票/餐费/其他）、金额、说明，上传单据照片，提交后等待审核。
6. 「现金领款」：提交领款申请，查看发放状态。
7. 「团报汇总」：订单数、报账金额、现金领款、结余。
8. 数据与后台同源，仅本社可见。

## 5. 景区员工端（小程序 / App）

1. 登录：选择「景区员工」，账号 `scenic01` / `admin123`。
2. 「扫码验票」：点击「扫码」调用微信扫码，或手动输入二维码内容；选择闸口；确认验票。
   - 成功：显示游客、闸口、第几次核销（多日票会标注）。
   - 失败：门票无效/已退款/未到游玩日/已使用完毕。
3. 「实时客流」：今日入园、拥堵预警、区域流量。
4. 「验票记录」：最近核销记录。
5. 「公告」：接收对账/客流提醒。
6. 仅本景区数据可见。

## 6. 供应商开放端

登录：`hotel01` / `bus01` / `rest01`，密码 `admin123`（H5 或独立入口）。

- 查看/维护自身资源库存、协议价（酒店房态、车辆司机）。
- 采购单「一键确认/拒绝」。
- 查看结算单与「两套账」：供应商账（应收/已结/待结）与旅行社账（结算金额/已付/待付）。
- 仅见自身订单与结算，越权返回 403。

## 7. 分销商（H5）

1. 门户右上角「分销商」→ 账号 `md001` / `admin123`。
2. 「实时报价」查看分销价与余位；「去下单」进入线路详情。
3. 「分销订单」「佣金明细」查看订单与入账状态。
4. 换线、按报名人数排序由接口/运营后台配合使用。

## 8. 游客（小程序 / H5 / App）

### 8.1 浏览与预订

1. 首页搜索/目的地/热门线路 → 线路详情（行程、价格、包含不含、退改、余位）。
2. 选择团期 → 填写成人/儿童数、联系人、游客实名信息 → 提交预订。
3. 订单详情「去支付」（演示为模拟微信支付）→ 状态变为待确认/已成团。
4. 支付成功后可在「消息中心」收到报名确认。

### 8.2 订单与核销

- 「我的订单」查看状态、金额、出团日期。
- 订单详情展示核销凭证（订单号），到店/导游扫码核销。
- 已支付订单可「申请退改」，按规则计算可退金额，等待审批。
- 「电子合同」可生成并在线签署。

### 8.3 会员与协议

- 会员中心：UnionID、等级、积分、优惠券、消费记录、会员卡。
- 消息中心：报名确认、成团、出团、退款、营销、合同。
- 我的：用户协议、隐私协议、多语言切换、客服电话。

## 9. H5 门户

- 首页：平台/旅行社介绍、目的地、热门线路、公告。
- 全部线路：关键词/目的地/天数筛选。
- 线路详情/预订：日历团期、实名信息、在线下单。
- 目的地攻略、机构官网（关于我们）。
- 订单查询：订单号 + 手机尾号，仅返回摘要（限流防撞库）。
- 游客中心 / 分销中心 / 分享落地页（携带来源标识）。

## 10. 常见问题

| 问题 | 处理 |
|---|---|
| 租户登录提示已停用/到期 | 联系平台续期或启用 |
| 平台下钻后不能保存 | 下钻为只读视图，需切回租户账号操作 |
| 上传图片失败 | 检查对象存储连接测试是否通过、文件大小 ≤100MB |
| 微信登录失败 | 本地保持 `WECHAT_MOCK=true`；生产配置真实 AppID/Secret 与合法域名 |
| 模板消息未收到 | 检查模板 ID、公众号配置、发送日志；未配置时降级为站内消息 |
| 验票提示已核销 | 防重复机制；多日票按有效天数 |
| 订单提示余位不足 | 排期库存已满或被并发占用，选择其他团期 |
| PDF 中文乱码 | 服务器安装中文字体（simhei/微软雅黑/Noto CJK） |
