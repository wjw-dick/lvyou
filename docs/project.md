# 项目文档

## 1. 项目背景

本项目建设一套面向全国中小型旅行社的 **SaaS 多租户旅游经营管理平台**，对标「SaaS 焊工考试系统 / 中医馆数字化平台」的前后端分离 + 多端架构，业务域替换为旅游行业。

核心痛点：

1. 产品（线路）信息分散在 Excel/微信，无法一次上架多渠道。
2. 排期、收客、余位靠人工登记，易超售、成团判断滞后。
3. 订单从预订、支付、名单、出团、核销、退改缺乏闭环追踪。
4. 计调资源（酒店/用车/餐厅/门票/地接）与导游报账、供应商结算脱节。
5. 分销商/门市报价、佣金、换线靠人工，渠道之间价格不透明。
6. 电子合同、实名制、保险、景区票务等合规环节缺失。
7. 多端（小程序/公众号/H5/App）账号不互通，会员无法沉淀。

## 2. 产品定位与角色

| 角色 | 能力边界 |
|---|---|
| system 超级管理员（平台端） | 全国跨租户统计、租户开通/停用/续期/配额、全局标准字典、平台参数、平台审计；可下钻任意租户**只读**查看 |
| 租户管理员（旅行社老板/门店负责人） | 本租户全部业务与配置、用户与角色、数据字典扩展、审计、报表 |
| 计调 | 产品、排期、资源采购、排团、出团计划 |
| 销售/门店店长 | 订单、名单、出团通知、核销、退改 |
| 财务 | 结算单、发票、分账、佣金、报表导出 |
| 导游 | 带团行程、点名、现金领款、回团报账、供应商直拨 |
| 分销商/门市 | 实时报价、余位、下单、佣金与结算 |
| 供应商（酒店/车队/餐厅/地接） | 自身资源/房态/车辆、采购单确认、结算、两套账 |
| 景区员工 | 门票、分时库存、扫码验票、客流、对账提醒 |
| 游客 | 线路浏览/预订/支付/订单/核销凭证/合同/会员/消息 |
| 景区管理 | 景区档案、门票产品、库存限流、验票规则、客流、二销、停车、营收 |

## 3. 总体架构

```
                     ┌──────────────┐
  平台端/租户端  ───▶ │  admin-web   │ ─┐
  H5 门户/游客/分销 ─▶ │  portal-web  │ ─┤
  微信小程序多角色 ──▶ │ miniprogram  │ ─┼─▶ Spring Boot 3 /api ──▶ MySQL 8
  Flutter App     ───▶ │  app         │ ─┘        │  ├─ Redis（缓存/锁/限流/编号）
                      └──────────────┘            │  ├─ RabbitMQ（通知/延迟任务）
                                                  │  ├─ 对象存储（本地/S3/OSS/COS/MinIO）
                                                  │  └─ 微信开放平台（UnionID/模板消息）
```

- 同一套后端按 `userType`（PLATFORM/TENANT/MEMBER/GUIDE/SCENIC/DISTRIBUTOR/SUPPLIER）分流。
- 租户数据由 MyBatis-Plus 租户插件强制注入 `tenant_id`；平台超管未选租户时跨租户，选中租户后只读。
- 多端统一 `UnionID` 会员档案，登录态为统一 JWT。

## 4. 功能模块清单

### 4.1 平台端
- 全国数据看板（旅行社数/产品数/订单数/销售额/会员数，按租户下钻）
- 租户管理（开通、编辑、配额、续期、停用/启用、到期自动停用）
- 全局标准字典（目的地/出发地/天数/价格单位/币种/订单状态/结算类型/证件类型/退改模板）
- 平台参数（成团最低人数、出团预警天数、结算账期、电子合同/OTA/短信开关）
- 平台公告、平台用户、平台审计日志

### 4.2 租户端
- 工作台：今日订单、销售额、产品数、会员数、7 日排期、预警清单、配额使用
- 产品中心：线路/签证/机票/酒店/门票/租车/邮轮/商品；行程 D1~Dn、价格、库存、费用说明、退改、图文攻略、多语言、多渠道上架、Excel 导入导出
- 目的地/景点/攻略
- 排期管理：日历视图、出团计划、批量生成、成团状态、红黄灯预警、计划书 PDF、推送导游
- 订单管理：实名下单、支付、确认、名单、出团通知、扫码核销、退改审批/退款、订单轨迹、名单导出
- 导游管理：档案（证号/等级/可带团时间/证件加密）、带团安排、报账审核、报账汇总
- 计调资源：供应商档案/资源库存/协议价、采购单、供应商确认、超售校验、OP 排团匹配
- 财务结算：结算单（按合作方/单团/订单）、审批、打款、收付款计划、发票、分账、佣金
- 分销管理：分销商/门市、独立商城、分销报价、佣金、换线操作、按报名人数排序、推广链接/裂变
- 电子合同：模板、生成、签署（人脸/CA 模拟）、PDF 下载、文旅局同步（预留）、验真
- 会员运营：UnionID 会员、等级/积分/余额、优惠券、营销活动、积分商城、会员卡/储值、复购分析
- 景区：景区档案、门票产品（单票/联票/年卡/团队/优待）、分时库存/日限流、验票、客流、区域拥堵、二销商户、停车、导览、营收对账
- 内容增长：UGC 游记/攻略/点评/问答/晒单、点赞/评论/收藏/举报、敏感词+人工审核、定制游、行程规划器、直播（预留）
- 报表中心：经营报表（收客/成团率/毛利/导游报账/供应商结算/分销佣金/会员）、Excel 导出、经营驾驶舱
- 系统设置：用户、角色权限（菜单树）、数据字典、租户配置、对象存储（5 驱动）、微信配置、消息配置、菜单可视化、审计日志
- 保险与合规：保险产品/投保/保单、质保金台账、到期预警

### 4.3 多端
- 游客端小程序：首页/搜索/目的地/线路详情/行程/日历团期/实名预订/支付/订单/核销凭证/电子合同/会员/消息/协议/多语言/tabBar 可视化
- 导游端小程序：带团行程、游客名单、点名、现金领款、回团报账（拍照上传）、供应商直拨、团报
- 景区员工端小程序：扫码验票、人工输入、闸口选择、实时客流、区域拥堵、验票记录、公告
- 公众号：关注欢迎语、关键词回复、自定义菜单可视化同步、素材/标签/粉丝/群发（模拟）、网页授权 URL、模板消息
- H5 portal-web：公开门户（SEO/双语 hreflang）、线路列表/详情/预订、目的地攻略、机构官网、订单查询、游客中心、分销中心、分享落地页
- Flutter App：游客端（线路/详情/预订/订单/会员）+ 导游端（带团/名单/点名/团报），主题与底部导航可后台配置
